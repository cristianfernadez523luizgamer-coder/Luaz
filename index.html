Guia APK (GitHub + Kodular)

Este arquivo index.html já está pronto para hospedar no GitHub Pages (HTTPS) e empacotar como APK Android no Kodular.

3 Passos para gerar o APK no celular:
  1. Salvar como index.html: Garanta que o arquivo na pasta Downloads esteja nomeado exatamente como index.html (sem números extras).
  2. GitHub Pages (HTTPS): Crie um repositório público no GitHub, envie o index.html, ative Settings → Pages e copie o link HTTPS gerado.
  3. Kodular WebView APK: Crie um projeto no Kodular, adicione o componente WebViewer ocupando a tela toda, cole o link HTTPS na Home URL e clique em Export → Android APK.
